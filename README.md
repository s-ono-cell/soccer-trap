# サッカー・トラップ解析 サポータス (TrapForm) v1.0.0

高校生やサッカー初心者が、iPadやスマートフォンで撮影したトラップ（ファーストタッチ／ファーストコントロール）動画を見て、フォームを確認・記録できる日本語Webアプリケーションです。

AIの自動推定に頼り切るのではなく、利用者が自分の目でコマ送りしながら「4つの重要局面」を選び、フォームの振り返りや記録が行えるよう設計されています。

---

## 🌟 主な特徴

1. **右足・左足（蹴り足）の切り替え対応**
   - 利き足／トラップを行う足（右足・左足）を選択可能。
   - 選択に応じて、トラップ足（シアン）と軸足（アンバー）を自動で識別し、膝や股関節の角度を計測します。

2. **真横（メイン）＋ 後ろ（補助）の2視点分析**
   - **真横視点**: 膝のクッション、股関節の屈曲、体幹の前傾姿勢の確認に最適。
   - **後ろ視点**: 体幹の左右のブレ、頭・重心の位置、肩や骨盤の水平度を確認。

3. **MediaPipe Pose による動画への骨格オーバーレイ**
   - Google MediaPipe Pose Landmarker（WASM/WebGL）をブラウザ内で実行。
   - 動画の上に推定された骨格ライン、関節ポイント、リアルタイム関節角度を重ねて表示します。

4. **初心者・タッチ操作に特化した大型UI**
   - iPad Safariやスマートフォンでも押しやすい最低44px以上の大きなボタン。
   - コマ送り（1フレーム進む／戻る、0.05秒調整）、スロー再生（0.25x / 0.5x / 1.0x）、タッチしやすいシークバー。

5. **4つの重要局面の手動ピン止め**
   - ① **構え・アプローチ**：ボールが来る前の重心・体幹前傾
   - ② **インパクト直前**：軸足の踏み込みとトラップ足の迎え出し
   - ③ **インパクト・ファーストタッチ**：ボールの勢いを吸収（クッション）する瞬間
   - ④ **コントロール後・次動作**：次のパスやドリブルへの体重移動
   - AIがインパクト候補時刻を粗解析で探索し、ワンタップ代入も可能です。

6. **インパクト基準の2画面同期再生**
   - 後ろ動画も読み込んだ場合、手動ピン止めした「③ インパクト」の瞬間を基準にして2本の動画をピタリと同期。
   - 横からの膝のクッションと、後ろからの左右のブレを同一タイムラインで比較できます。

7. **診断チェックシート & コーチングアドバイス**
   - 各局面における「良好」「要確認」の目安判定と、改善のためのアドバイスを表示。

8. **詳細データのCSVダウンロード**
   - 局面番号、時刻、各関節角度、推定3次元座標（X, Y, Z, 信頼度）を日本語Excel対応のUTF-8（BOM付き）CSVで一括保存できます。

9. **完全ローカル処理（プライバシー安心）**
   - 動画ファイルや解析データは外部サーバーに一切送信されず、すべてお使いの端末ブラウザ内でのみ処理されます。

10. **キャッシュ対策とバージョンバッジ**
    - 画面上部にバージョンバッジ（`v1.0.0`）を表示。
    - スクリプトURLにクエリパラメータ（`?v=1.0.0`）を付与し、更新時の古いキャッシュ読み込みを防止。

## 📖 使い方（ステップバイステップ）

### ステップ 1: 設定
- トラップを行う足（「右足」または「左足」）を選択します。
- 必要に応じて身長を入力します（デフォルト: 170cm）。

### ステップ 2: 動画の選択と解析
- **真横動画（必須）**：選手の体の真横90度から撮影した動画を選択します。
  - 手元に動画がない場合は、「テスト用サンプル動画を生成して試す」ボタンを押すと、即座にブラウザ内でサンプル動画が生成されて全機能を試せます。
- **後ろ動画（任意）**：選手の真後ろから撮影した動画がある場合は追加します。
- 動画を選ぶと、AIが全体の粗探索を行い、インパクト周辺を精密解析します（Coarse-to-Fine 解析）。

### ステップ 3: コマ送り確認と4局面ピン止め
- 動画を再生、または「+1F / -1F」ボタンで1コマずつ送り、4つの局面の瞬間に合わせます。
- 各カードの「現在フレームをピン止め」ボタンをタップして確定します。

### ステップ 4: フォーム診断チェック
- ピン止めされた瞬間の関節角度や体幹の傾き、アドバイスを確認します。
- 後ろ動画がある場合は、インパクト同期2画面ビューで同時に見比べられます。

### ステップ 5: CSVレポートの保存
- 画面最下部の「CSVレポートを保存」ボタンを押すと、全タイムスタンプと関節角度が入ったCSVファイルが端末にダウンロードされます。

## 📷 撮影上の注意点

より正確に骨格を推定するための推奨撮影条件です：

1. **全身とボールを常に画面に入れる**
   - 頭のてっぺんから足先、ボールの飛来軌道が画面から見切れないよう、やや引き気味の構図で撮影してください。
2. **カメラをしっかり固定する**
   - 三脚やベンチ、グラウンド脇の荷物などにスマホ・iPadを置いて固定してください。手ブレがあると骨格推定のブレにつながります。
3. **明るい環境で撮影する**
   - 日中の屋外または十分な照明がある体育館などで撮影してください。逆光や暗所では足元の輪郭が認識しにくくなります。
4. **10秒程度の短い動画にトリミングする**
   - トラップ動作の前後2〜3秒（合計5〜10秒程度）にスマホの写真アプリでトリミングしてから読み込むと、解析が数秒で完了し端末のバッテリーやメモリ負荷を抑えられます。
   - ※15秒を超える動画は、自動的に先頭15秒を解析対象とします。

## ⚠️ 解析の限界と免責事項

- **単眼2次元動画からの推定**: 本アプリの骨格推定・関節角度・速度計算は、スマートフォン等の1台のカメラで撮影された2次元映像に基づくAI推定値であり、モーションキャプチャ等の精密な3D計測とは異なります。
- **後方動画からの膝角度の限界**: 後ろからの撮影では、前後の膝の曲がりがカメラの奥行き軸と重なり計測誤差が大きくなります。後方動画は体幹の左右傾きや重心バランスの確認を中心にご利用ください。
- **目安としての判定**: チェック項目における「良好」「要確認」の判定は一般的な指導目安であり、選手の身長・骨格・プレースタイルによって最適なフォームは異なります。

## 🚀 Netlify へのデプロイ方法

本アプリはサーバーやバックエンドAPIを一切必要としない、純粋な静的Webアプリケーション（SPA）です。Netlifyでそのまま即座に公開できます。

### デプロイ設定
- **Build Command**: `npm run build`
- **Publish Directory**: `dist`
- **Node.js バージョン**: 18以上 (20推奨)

### 手順
1. GitHub等のリポジトリに本プロジェクトをプッシュします。
2. Netlifyの管理画面で「Add new site」→「Import an existing project」を選択します。
3. リポジトリを選択し、上記の設定（Build Command: `npm run build` / Publish Directory: `dist`）を指定して「Deploy」をクリックします。
4. 数十秒でビルドが完了し、公開URLが発行されます。
